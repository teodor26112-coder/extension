# Ozon Price Tracker

Расширение для Chrome, которое позволяет отслеживать цены товаров на маркетплейсе Ozon прямо из панели браузера.

## Возможности

- хранение списка товаров и целевых цен в `chrome.storage`;
- автоматическая проверка цен каждые 30 минут через сервис-воркер;
- ручное обновление цен одной кнопкой в popup-е;
- уведомления браузера при снижении стоимости до целевого значения.

## Структура

- `manifest.json` — описание расширения (Manifest V3);
- `background.js` — сервис-воркер, который опрашивает Ozon и отправляет уведомления;
- `popup.html`, `popup.js`, `popup.css` — интерфейс для добавления и управления товарами;

## Сборка и установка

1. Соберите файлы расширения в одну папку (в репозитории уже всё готово).
2. Откройте в Chrome страницу `chrome://extensions` и включите режим разработчика.
3. Нажмите «Загрузить распакованное» и выберите папку проекта.
4. После установки нажмите на иконку расширения, чтобы открыть popup и добавить товары.
