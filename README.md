# Ozon Price Tracker

Расширение Google Chrome помогает отслеживать цены на карточках товаров маркетплейса [Ozon](https://www.ozon.ru/) и присылает уведомления, когда стоимость падает ниже заданного порога. Интерфейс позволяет видеть текущую цену, среднюю стоимость, изменение цены и график динамики. Все данные записываются в файл во внутреннем файловом хранилище расширения, поэтому они не пропадут даже после очистки памяти браузера.

## Возможности

- Кнопка «Следить за ценой» появляется на карточках товаров Ozon и добавляет позицию в отслеживание одним кликом.
- Popup-окно расширения отображает список отслеживаемых товаров, показывает текущие цены, средние значения и изменения, а также даёт настроить порог уведомления для каждого товара.
- Встроенный график отображает историю изменения стоимости.
- Глобальная настройка интервала проверки цен (минимум 5 минут).
- Сервис-воркер периодически загружает страницы товаров, вычисляет статистику и сохраняет историю в файл `ozon_price_tracker_data.json` во внутреннем файловом хранилище.
- Уведомления браузера срабатывают при падении цены ниже указанного порога.
- Отдельная страница «Все отслеживаемые товары» доступна по кнопке в popup.
- Кнопка «Обновить сейчас» выполняет ручную проверку цен и обновление графиков.

## Установка (максимально подробно)

1. **Скачайте проект.**
   - Нажмите зелёную кнопку `Code` на странице репозитория.
   - Выберите `Download ZIP` и сохраните архив в удобную папку.
   - Кликните правой кнопкой по скачанному архиву и выберите «Извлечь» / «Распаковать сюда». В итоге должна появиться папка `extension` с файлами.
2. **Откройте Google Chrome.**
3. **Перейдите в раздел расширений.**
   - В адресной строке введите `chrome://extensions` и нажмите Enter.
4. **Включите режим разработчика.**
   - Справа сверху на странице расширений переведите переключатель «Режим разработчика» в активное положение.
5. **Установите расширение из папки.**
   - Нажмите кнопку «Загрузить распакованное» (Load unpacked).
   - В открывшемся окне выберите распакованную папку `extension` и нажмите «Выбрать папку».
   - Расширение появится в списке иконок, а также в панели инструментов Chrome.
6. **Закрепите значок (по желанию).**
   - Нажмите на значок пазла справа от адресной строки.
   - Найдите `Ozon Price Tracker` и нажмите на кнопку «закрепить», чтобы значок всегда был виден.

## Настройка и использование

1. **Добавление товара с карточки Ozon.**
   - Откройте любую карточку товара на `ozon.ru`.
   - В правом нижнем углу появится плавающая кнопка «Следить за ценой».
   - Нажмите на неё — товар автоматически добавится в список отслеживания. Если нужно, настройте порог уведомления позднее в popup.
2. **Добавление товара вручную.**
   - Кликните по значку расширения.
   - В форме укажите ссылку на товар Ozon и желаемый порог цены. Название можно заполнить вручную.
   - Нажмите «Добавить в отслеживание».
3. **Настройка порога уведомлений.**
   - В карточке товара внутри popup измените значение «Порог уведомления» и нажмите «Сохранить».
4. **Изменение частоты проверки.**
   - В блоке «Настройка обновления» укажите интервал в минутах (не меньше 5). Изменение вступает в силу сразу.
5. **Просмотр истории цен.**
   - В каждой карточке отображается график изменений. Наведите курсор, чтобы приблизиться к точкам.
   - Нажмите кнопку ↗ в шапке popup, чтобы открыть отдельную страницу со всеми товарами и увеличенными графиками.
6. **Ручное обновление.**
   - Нажмите кнопку ⟳ в popup или кнопку «Обновить сейчас» на странице списка. Расширение мгновенно выполнит проверку цен и обновит данные.
7. **Удаление товара.**
   - В карточке товара нажмите «Удалить». Элемент исчезнет из списка и из файла данных.
8. **Где хранятся данные.**
   - История и настройки записываются в файл `ozon_price_tracker_data.json`, который находится во внутреннем файловом хранилище расширения (Origin Private File System). Эта область недоступна для очистки стандартными средствами «Очистить данные браузера», поэтому все товары сохраняются даже после очистки кэша или перезапуска Chrome.

## Структура проекта

```
.
├── background.js          # сервис-воркер, опрос цен, уведомления
├── contentScript.css      # стили плавающей кнопки и тостов на ozon.ru
├── contentScript.js       # кнопка «Следить за ценой» и отправка данных в фоновый скрипт
├── manifest.json          # описание расширения и разрешений
├── popup.css              # стили всплывающего окна
├── popup.html             # интерфейс управления
├── popup.js               # логика popup: добавление, графики, настройки
├── storage.js             # модуль сохранения состояния в файл
├── tracked.css            # стили отдельной страницы со списком товаров
├── tracked.html           # страница с расширенным списком
├── tracked.js             # логика страницы списка
├── ui-helpers.js          # функции форматирования и рисования графиков
└── README.md              # документация
```

## Проверка

Расширение не требует сборки. После внесения изменений перезагрузите его в `chrome://extensions` (кнопка «Обновить») и протестируйте на карточках Ozon.
