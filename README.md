# Modular Telegram Bot

Этот проект демонстрирует, как построить модульного Telegram-бота на Python с
разделением функций по независимым модулям: админка и статистика, анти-спам,
анти-флуд, голосование за мут и игровая система с опытом. Структура позволяет
легко добавлять платные модули и подключать центральную админку для сбора
данных.

## Что умеет бот
- **Админка**: базовая статистика чатов и пользователей, заготовка для учёта
  платных подписок.
- **Анти-спам**: удаляет сообщения с нежелательными словами и ссылками.
- **Анти-флуд**: ограничивает частоту сообщений от одного пользователя.
- **Голосование за мут**: пользователи могут голосовать за временный мут
  нарушителя.
- **Игра с опытом**: каждое сообщение начисляет опыт, уровни повышаются
  автоматически.

## Структура проекта
```
my_telegram_bot/
├── bot.py            # точка входа бота
├── config.py         # настройки (токен, лимиты, цены на модули)
├── requirements.txt  # зависимости
├── database/         # работа с БД (SQLite по умолчанию)
├── modules/          # отдельные модули
│   ├── admin/        # статистика, подписки
│   ├── anti_spam/    # фильтр спама
│   ├── anti_flood/   # защита от флуда
│   ├── mute/         # голосование за мут
│   └── game/         # опыт и уровни
```

## Подготовка: даже если вы «не дружите с компьютером»
Следуйте шагам последовательно. Если что-то не получается — перепроверьте, что
все шаги выполнены по порядку.

1. **Установите Python 3.10+**
   - Зайдите на [python.org/downloads](https://www.python.org/downloads/) и
     скачайте установщик для своей системы (Windows/Mac/Linux).
   - При установке на Windows поставьте галочку «Add Python to PATH».

2. **Создайте бота и токен у BotFather**
   - Откройте Telegram и найдите пользователя `@BotFather`.
   - Отправьте команду `/start`, затем `/newbot`.
   - Придумайте имя и @username для бота. BotFather вернёт токен вида
     `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11` — сохраните его, он понадобится
     ниже.

3. **Скачайте проект**
   - Нажмите кнопку **Code → Download ZIP** на странице репозитория или выполните
     в терминале:
     ```bash
     git clone <ссылка_на_репозиторий>
     cd extension
     ```

4. **Создайте виртуальное окружение (рекомендуется)**
   - В терминале внутри папки проекта выполните:
     ```bash
     python -m venv .venv
     source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
     ```
   - Активированное окружение защитит системные пакеты и упростит установку
     зависимостей.

5. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

6. **Настройте токен и опции**
   - Откройте файл `config.py` и замените `YOUR_TOKEN` на токен от BotFather.
     **Важно:** токен должен быть в кавычках (`"123456:ABC..."`), иначе Python
     выдаст ошибку синтаксиса.
   - Убедитесь, что токен скопирован без пробелов и переносов строк. При запуске
     бот автоматически убирает случайные пробелы и предупреждает об этом в
     логах. Если видите ошибку `InvalidToken`, скопируйте токен заново в одной
     строке и перезапустите бота.
   - При желании измените настройки спама, флуда, длительность мута и скорость
     прокачки опыта — это базовые значения по умолчанию.
   - Можно вместо правки файла указать переменную окружения перед запуском:
     ```bash
     export BOT_TOKEN="123456:ABC..."
     ```

7. **Запустите бота**
   ```bash
   python bot.py
   ```
   - Если всё в порядке, в консоли появится сообщение «Бот запущен…».
   - Откройте Telegram, найдите вашего бота и отправьте команду `/start`.

## Использование команд
- `/start` — приветствие и краткое описание.
- `/help` — список основных команд.
- `/stats` — статистика по чатам и пользователям (требует, чтобы бот был
  администратором для чтения статистики в группе).
- `/check_spam <текст>` — проверить сообщение на спам вручную.
- `/spam_config`, `/flood_config`, `/game_config`, `/mute_config` — настройка
  модулей в конкретном чате (только для администраторов чата).
- `/spam_status`, `/flood_status`, `/game_status`, `/mute_status` — показать
  текущие настройки модулей.
- `/mute_vote` — запустить голосование за мут. Проще всего ответить этой
  командой на сообщение нарушителя.
- Сообщения без команд автоматически дают опыт и могут повышать уровень.

## Настройка модулей в каждом чате
Все модули можно настраивать прямо из чата. Команды должны вызывать
администраторы группы, иначе настройки не изменятся.

- **Анти-спам**: `/spam_config keywords=слово1,слово2 enabled=1 notification=Текст`.
  - Ключевые слова разделяются запятой, `enabled=0` отключает фильтр.
  - Посмотреть текущие значения: `/spam_status`.
- **Анти-флуд**: `/flood_config cooldown=3 enabled=1 warning=Сообщение`.
  - `cooldown` — пауза между сообщениями одного пользователя в секундах.
  - Посмотреть текущие значения: `/flood_status`.
- **Игра (опыт/уровни)**: `/game_config xp_per_message=5 xp_per_level=50 enabled=1`.
  - `xp_per_message` — сколько опыта начисляется за сообщение.
  - Посмотреть текущие значения: `/game_status`.
- **Голосование за мут**: `/mute_config threshold=3 duration=300`.
  - `threshold` — сколько голосов нужно для блокировки.
  - `duration` — длительность мута в секундах.
  - Посмотреть текущие значения: `/mute_status`.

## База данных и админка
- По умолчанию используется SQLite-файл `database/bot.sqlite3`, который создаётся
  при первом запуске.
- Таблицы хранят чаты, пользователей, подписки и голоса за мут. Логика вынесена
  в `database/manager.py`.
- Команда `/stats` выводит сводку: количество чатов, сообщений, пользователей и
  активных подписок.

## Как добавить платные модули в будущем
- В `config.py` есть словарь `PAID_MODULES`. Можно расширять его новыми ключами,
  а в базе использовать `subscriptions.paid_modules` для учёта активированных
  функций.
- Добавьте новый модуль в папку `modules/<module_name>/`, реализуйте функцию
  `add_handlers(application, db)` и подключите её в `bot.py`.

## Полезные советы
- Держите бота в режиме администратора в группах, чтобы удаление сообщений и
  муты работали корректно.
- Для деплоя на сервер можно использовать Supervisor/systemd: запустите виртуальное
  окружение, выполните `python bot.py` и настройте перезапуск при сбоях.
- Резервное копирование: периодически копируйте файл `database/bot.sqlite3`.

Удачной работы! Если что-то не получилось — перепроверьте токен, права бота в
чате и наличие установленного Python.
