# PriceHunt Extension

Проектная заготовка браузерного расширения (Manifest v3) для отслеживания и сравнения цен в Chrome/Firefox.

## Структура проекта
- `manifest.json` — конфигурация расширения: описание, права, фоны, контент-скрипты и всплывающее окно.
- `icons/` — базовые заглушки иконок разных размеров, указанные в манифесте.
- `background/service-worker.js` — сервис-воркер фона: логирование установки и шаблон обмена сообщениями.
- `content-scripts/pricehunt.js` — контент-скрипт, собирающий цены на странице и возвращающий их по запросу.
- `popup/index.html` — каркас всплывающего окна с элементами интерфейса (заголовок, кнопка, список цен).
- `popup/popup.js` — логика UI: запрос данных у активной вкладки и рендер списка цен или сообщения об отсутствии данных.
- `popup/popup.css` — стили оформления всплывающего окна и списка цен.
